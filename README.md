# Nova — SaaS Landing Page

A modern, responsive landing page for a fictional SaaS product, built entirely with **HTML and CSS** — no JavaScript, no frameworks.

## 📖 About

Nova is a portfolio project designed to demonstrate professional front-end fundamentals: semantic HTML, a scalable CSS architecture, responsive design, and thoughtful UI/UX — all without relying on JavaScript or any CSS framework.

## ✨ Features

- Fully responsive layout (mobile, tablet, desktop)
- Sticky navigation with smooth-scroll anchor links
- CSS-only mobile hamburger menu (checkbox hack — no JavaScript)
- CSS-only accordion FAQ section using native `<details>`/`<summary>`
- Reusable component-based CSS architecture with custom properties (variables)
- Hover states, entrance animations, and `prefers-reduced-motion` support
- Accessible focus states (`:focus-visible`) and semantic HTML structure

## 🛠️ Technologies Used

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, custom properties, animations, media queries)
- No JavaScript, no frameworks, no libraries
